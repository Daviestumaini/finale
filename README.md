# 📝 Sticky Notes Todo App

A modern and minimal Todo List web app built using **HTML**, **CSS**, and **Vanilla JavaScript**.

This app lets users:
- Add tasks
- Mark tasks as completed
- Delete tasks
- Clear completed tasks
- Toggle dark mode
- Save tasks using Local Storage

The UI is inspired by colorful retro sticky notes with soft shadows and playful rotations.

---

## ✨ Features

- ✅ Add new tasks
- ✅ Mark tasks as completed
- ✅ Delete tasks
- ✅ Clear all completed tasks
- ✅ Persistent storage with `localStorage`
- ✅ Dark mode toggle
- ✅ Responsive design
- ✅ Retro sticky note UI
